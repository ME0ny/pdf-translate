# 📄 PDF Editor & AI Translator

Клиентский редактор и переводчик PDF-документов с интеграцией искусственного интеллекта. 
Весь процесс анализа, верстки и сохранения происходит **локально в вашем браузере**. Серверная часть требуется только для отправки запросов к API языковой модели.

## 🚀 Быстрый старт

Для запуска проекта не требуется установка Node.js, Python или каких-либо сложных зависимостей.

1. **Скачайте код**:
   - Нажмите кнопку `Code` -> `Download ZIP` на GitHub и распакуйте архив.
   - *Или клонируйте репозиторий*: `git clone https://github.com/ME0ny/pdf-translate.git`
2. **Откройте папку** с проектом в редакторе **VS Code**.
3. **Установите расширение** [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) (если оно еще не установлено).
4. **Запустите**: Откройте файл `index.html`, нажмите правой кнопкой мыши и выберите **"Open with Live Server"** (или нажмите кнопку `Go Live` в правом нижнем углу VS Code).
5. Приложение откроется в вашем браузере по адресу `http://127.0.0.1:5500`.

## ⚙️ Настройка ИИ

Перед началом работы необходимо настроить подключение к языковой модели:

1. В правом верхнем углу нажмите кнопку **⚙ ИИ**.
2. Заполните поля в открывшемся окне:
   - **Base URL**: Адрес API (например, `https://routerai.ru/api/v1` или другой совместимый провайдер).
   - **API-ключ**: Ваш персональный ключ доступа.
   - **Модель**: Рекомендуется использовать `deepseek/deepseek-v4.1-flash-1017` (или актуальную быструю модель вашего провайдера).
   - **Параллельных запросов**: Укажите от `5` до `10` (для баланса между скоростью и стабильностью).
   - **Запросов в минуту (RPM)**: Укажите лимит вашего тарифа (поставьте `0`, если лимита нет).
3. Нажмите кнопку **Проверить**, чтобы убедиться, что ключ и модель работают корректно.
4. Нажмите **Сохранить**.

## 📖 Инструкция по использованию

Для достижения наилучшего результата и стабильной работы браузера следуйте этому алгоритму:

1. **Загрузка документа**:
   - Нажмите кнопку **📂 Открыть PDF**.
   - ⚠️ **ВАЖНО**: Для надежности и избежания переполнения оперативной памяти браузера **загружайте файлы объемом не более 100 страниц**. Для больших документов рекомендуется предварительно разделить их на части.
2. **Анализ**:
   - Дождитесь завершения автоматического анализа документа (поиск текста, таблиц и изображений). Статус отображается в верхней панели.
3. **Перевод**:
   - В боковой панели убедитесь, что выбрана вкладка **Текст**.
   - Нажмите кнопку **🌐 Весь документ**.
   - Следите за индикатором прогресса. **Не закрывайте и не обновляйте вкладку браузера** до завершения процесса.
4. **Редактирование (опционально)**:
   - Вы можете вручную исправить любой переведенный фрагмент в боковой панели. Текст на странице обновится автоматически.
   - Для изображений можно использовать инструмент "✚ Выделить вручную", чтобы заменить или удалить графику.
5. **Сохранение результата**:
   - Когда перевод завершен и вас устраивает результат, нажмите кнопку **💾 Сохранить PDF** в верхней панели.
   - Браузер скачает готовый файл с суффиксом `_edited.pdf`.

## 🛠 Технологии

- **PDF.js**: Рендеринг и извлечение текстового/векторного слоя PDF.
- **PDF-Lib + Fontkit**: Модификация PDF-документа, внедрение шрифтов и сохранение результата.
- **IndexedDB**: Локальное кэширование анализа страниц для мгновенного повторного открытия документа.
- **Vanilla JS**: Чистый JavaScript без тяжелых фреймворков для максимальной производительности в браузере.

## ⚠️ Ограничения

- Приложение полностью клиентское. Тяжелые документы (>100 стр. или с сложной векторной графикой) могут требовать много оперативной памяти (RAM).
- Качество перевода и сохранения форматирования зависит от исходной структуры PDF-файла (сканы обрабатываются хуже, чем текстовые PDF).
